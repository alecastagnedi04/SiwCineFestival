# SiwCineFestival
SiwCineFestival è un'applicazione web dedicata alla gestione di festival cinematografici. Permette di consultare festival, film, registi, attori e programmi delle proiezioni, oltre a consentire agli utenti registrati di pubblicare recensioni.
Gli amministratori possono gestire i contenuti e programmare le proiezioni.
Il progetto è sviluppato con Java, Spring Boot, JPA/Hibernate, PostgreSQL, Thymeleaf e React.
